STARFALL ARENA is an original neon arena-survival shooter: pilot a lone starfighter through escalating waves of Chasers, Weavers, Splitters and Shooters, vacuum up XP shards, and choose game-changing upgrades on every level-up. Clear Wave 10 to win the sector — then push your score in endless mode against the Dreadnought boss that returns every five waves.

## Run it

```sh
cd game && python3 -m http.server 8080  — then open http://localhost:8080
```

Controls: WASD / arrows to move, mouse to aim, click / hold or Space to fire, Shift to dash, P / Esc to pause, M to mute.
